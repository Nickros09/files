Один DEB для установки без Интернета
===================================
Asterisk 18.6.0 / pjproject 2.10 / jansson 2.12 / amd64
Назначение: Astra Linux SE 1.6 «Смоленск», Intel Core i5-760.

Файл: asterisk-custom_18.6.0-2+astra16.bundle_amd64.deb
Включены 55 внешних прикладных библиотек и две библиотеки Asterisk.
Они расположены в /usr/lib/asterisk/private. ELF RUNPATH направляет
загрузчик в этот каталог. Системные библиотеки не заменяются.
Список версий: BUNDLED-LIBRARIES.tsv.

Требуется штатная базовая ОС amd64 с glibc >= 2.24 и adduser.
Динамический загрузчик, glibc, NSS, базовые утилиты и systemd остаются
компонентами ОС. Это один DEB, а не полностью независимая от ОС программа.
Для уже собранных модулей не требуется скачивание библиотечных пакетов.
Произвольные дополнительные модули Asterisk в эту сборку не входят.

Установка под root из каталога со скачанным файлом:
  dpkg -i ./asterisk-custom_18.6.0-2+astra16.bundle_amd64.deb
После настройки /etc/asterisk:
  systemctl enable asterisk
  systemctl restart asterisk
  systemctl status asterisk
  asterisk -rx 'core show version'
  asterisk -rx 'module show like pjsip'
  asterisk -rvvv

Имя пакета asterisk-custom сохранено. Новая версия обновляет предыдущую
18.6.0-1+astra16. Изменённые пользователем conffiles сохраняются по правилам
dpkg. Перед обновлением сделайте резервную копию конфигурации и данных.
С официальными пакетами asterisk/asterisk-config/asterisk-modules объявлен
конфликт. Установку поверх ручной сборки Asterisk не проверяли.

После установки служба автоматически не запускается. Работает от
пользователя asterisk. Примеры конфигурации входят; абоненты, транки,
TLS-сертификаты и доверенные CA для внешних сервисов настраиваются отдельно.
Для HTTPS можно использовать системный CA-файл, указав его в настройках.
Звуковые файлы приветствий и музыка ожидания не включены.

Проверено: dpkg -i без сети в чистом Debian 9; разрешение зависимостей
всех ELF-файлов; запуск PJSIP и остановка нативно и при эмуляции Nehalem.
На Astra и реальном i5-760 ещё нужна проверка; service manager и мандатный
контроль Astra в контейнере не воспроизводились.

Встроенные библиотеки обслуживаются вместе с этим пакетом: установка
обновлений системных библиотек не обновляет их частные копии.
Сборка не является официальным пакетом Astra Linux.
